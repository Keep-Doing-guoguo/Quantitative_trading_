# 术语表（中英对照）

## 市场与产品

- 股票（Stock）: 代表公司所有权份额的可交易证券。
- 期货（Futures）: 约定未来按规则交割的标准化合约。
- 指数（Index）: 反映一篮子资产表现的统计指标。
- ETF（Exchange Traded Fund）: 可在交易所买卖的基金份额。
- 主力合约（Main Contract）: 某时点成交最活跃的期货合约。
- 换月（Rollover）: 从临近到期合约切换到远月合约。

## 交易与执行

- 撮合（Matching）: 交易所按规则将买卖订单配对成交。
- 限价单（Limit Order）: 指定价格或更优价格成交的订单。
- 市价单（Market Order）: 以当时可成交价格尽快成交的订单。
- 成交回报（Fill Event）: 订单实际成交后的回报信息。
- 滑点（Slippage）: 预期成交价与实际成交价差异。
- 冲击成本（Market Impact）: 大额下单对市场价格造成的不利影响。

## 风险与资金

- 保证金（Margin）: 期货交易中为履约而冻结的资金。
- 杠杆（Leverage）: 以较小资金控制更大名义头寸的机制。
- 强平（Forced Liquidation）: 保证金不足时被强制平仓。
- 仓位（Position）: 在某标的上的多空持仓规模。
- 风险暴露（Risk Exposure）: 对某类风险因子的敏感程度。
- 最大回撤（Max Drawdown）: 历史净值峰值到后续谷值的最大跌幅。

## 绩效与组合

- 年化收益（Annualized Return）: 按年折算的收益率。
- 年化波动（Annualized Volatility）: 按年折算的收益波动程度。
- Sharpe 比率（Sharpe Ratio）: 单位波动风险对应的超额收益。
- 胜率（Win Rate）: 盈利交易占全部交易的比例。
- 盈亏比（Profit-Loss Ratio）: 平均盈利与平均亏损的比值。
- 相关性（Correlation）: 两组收益同向变化程度。
- 分散化（Diversification）: 通过低相关组合降低整体风险。

## 研发与系统

- 回测（Backtest）: 用历史数据模拟策略表现。
- 样本内（In-Sample）: 用于训练和调参的数据区间。
- 样本外（Out-of-Sample）: 用于验证泛化能力的数据区间。
- 过拟合（Overfitting）: 过度贴合历史噪声导致实盘失效。
- 幂等（Idempotency）: 重复执行请求不会产生额外副作用。
- 对账（Reconciliation）: 系统状态与交易通道状态核对过程。
