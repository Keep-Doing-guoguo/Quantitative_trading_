# 05 组合管理与绩效指标

## 概念名

收益、波动、Sharpe、最大回撤、胜率、盈亏比、相关性与分散化

## 正式介绍

单策略表现不等于组合表现。组合管理关注各策略/品种间相关性与风险预算分配。  
常用绩效指标包括：年化收益、年化波动率、Sharpe 比率、最大回撤、Calmar、胜率、盈亏比。  
相关性用于衡量收益同向程度，分散化通过低相关资产组合降低组合波动与尾部风险。

## 通俗介绍

不要把“会赚钱”和“赚得稳”混为一谈。  
- 收益高：赚得多。  
- 波动大：坐过山车。  
- Sharpe 高：单位风险赚得更有效率。  
- 分散化：别把鸡蛋放一个篮子里，篮子掉了就全碎。

## 为什么量化开发必须懂

如果只看收益，不看风险，系统会偏向高波动策略。  
如果不做组合级约束，多策略叠加后可能在同一风险因子上过度暴露。

## 在系统中的落点

- `data_handler`: 多资产收益序列对齐
- `strategy`: 提供策略级信号与置信度
- `risk_engine`: 风险预算、组合暴露上限
- `execution_router`: 按目标权重执行再平衡
- `backtest`: 组合层回测与指标输出
- `portfolio`: 持仓聚合、PnL 分解
- `monitoring`: 实时绩效看板与风险漂移告警

## 常见误区

1. 误区：胜率高就一定好。  
   纠正：低胜率但高盈亏比也可能很优秀。
2. 误区：Sharpe 高就没有风险。  
   纠正：Sharpe 对尾部风险不敏感，需要结合回撤与极端场景。
3. 误区：分散化就是多买几个品种。  
   纠正：关键是相关性结构，不是数量本身。

## 最小例子

两个策略单独都表现不错，但相关性高达 0.9。组合后回撤几乎同步放大。通过降低同向暴露并引入低相关策略，组合最大回撤显著下降。

## 3 道自测题（含答案）

1. 题目：为什么组合层必须统计相关性矩阵？  
   答案：用于识别风险集中，指导分散化与权重分配。
2. 题目：胜率和盈亏比如何配合看？  
   答案：胜率决定命中频率，盈亏比决定单次收益质量，两者共同决定长期期望。
3. 题目：哪类指标最能反映“是否抗跌”？  
   答案：最大回撤、回撤恢复时间以及极端情景下损失。
