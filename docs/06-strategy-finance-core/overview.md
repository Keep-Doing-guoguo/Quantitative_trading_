# 06 常见策略的金融逻辑

## 概念名

趋势跟踪、均值回归、动量、因子与策略失效

## 正式介绍

趋势跟踪假设价格存在可持续方向，常见于商品和宏观驱动市场。  
均值回归假设价格偏离均衡后会回归，常见于区间震荡场景。  
动量强调“强者恒强”在一定窗口内的延续性。  
因子模型通过可解释特征（价值、质量、波动等）构建横截面组合。  
任何策略都有失效条件，必须在开发阶段定义失效检测与下线机制。

## 通俗介绍

- 趋势策略：顺着浪走。  
- 均值回归：拉远了会弹回。  
- 动量：跑得快的短期还可能继续快。  
但市场会变，昨天有效的方法，明天可能失灵，所以要准备“刹车和下线”机制。

## 为什么量化开发必须懂

不理解策略背后的金融动因，会把随机噪声误当信号。  
系统层需要把策略假设写清楚，才能做有效监控和失效判断。

## 在系统中的落点

- `data_handler`: 提供策略所需特征序列
- `strategy`: 信号生成、参数配置、状态机
- `risk_engine`: 不同策略风险预算与熔断阈值
- `execution_router`: 按策略频率与容量约束执行
- `backtest`: 参数稳健性与样本外验证
- `portfolio`: 多策略组合与资金分配
- `monitoring`: 策略漂移检测与下线告警

## 常见误区

1. 误区：一个策略在回测好就可长期稳定。  
   纠正：市场结构变化会导致策略失效。
2. 误区：参数越多越聪明。  
   纠正：参数过多容易过拟合。
3. 误区：只要收益曲线平滑就可信。  
   纠正：可能是数据泄露或过度调参造成的假象。

## 最小例子

趋势策略在单边行情表现很好，但在震荡市频繁止损。系统通过市场状态识别模块降低该策略权重，同时提升更适合震荡环境的策略权重。

## 3 道自测题（含答案）

1. 题目：趋势和均值回归最大的前提差异是什么？  
   答案：趋势假设价格延续，均值回归假设价格回归。
2. 题目：为什么要做样本外验证？  
   答案：检验策略是否只记住了历史噪声，降低过拟合风险。
3. 题目：策略失效在系统中应如何响应？  
   答案：触发降权、停用或切换机制，而非继续盲目执行。
