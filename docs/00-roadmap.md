# 学习路线图（4 周）

本路线图聚焦“先能做系统，再逐步深入理论”。

## 第 1 周：市场与工具基础

- 学习目标
  - 理解交易市场的角色和规则边界
  - 区分股票与期货的产品属性和风险来源
- 对应文档
  - `docs/01-market-basics/overview.md`
  - `docs/02-instruments/overview.md`
- 输出物
  - 一份“我将交易哪些市场/哪些品种”的清单
  - 一份“合约关键字段”清单（乘数、最小变动价位、保证金率、交易时段）

## 第 2 周：交易机制与成本

- 学习目标
  - 理解订单如何成交、为什么会出现滑点
  - 理解手续费、保证金和强平如何影响策略生存
- 对应文档
  - `docs/03-trading-mechanics/overview.md`
- 输出物
  - 回测成本模型参数草案
  - 交易执行模块需要支持的订单类型清单

## 第 3 周：风险与组合

- 学习目标
  - 能把“风险”转成可执行规则
  - 能用核心绩效指标评估策略
- 对应文档
  - `docs/04-risk-and-money/overview.md`
  - `docs/05-portfolio-and-metrics/overview.md`
- 输出物
  - 风控阈值草案（日亏损限制、单品种暴露限制、最大回撤阈值）
  - 最小绩效报告模板（收益、波动、Sharpe、最大回撤、胜率）

## 第 4 周：策略金融逻辑与实盘约束

- 学习目标
  - 理解常见策略的金融动因与失效场景
  - 理解实盘与回测之间的现实差距
- 对应文档
  - `docs/06-strategy-finance-core/overview.md`
  - `docs/07-real-world-constraints/overview.md`
- 输出物
  - 一份策略假设列表（策略为什么可能赚钱、何时会失效）
  - 一份实盘上线前检查清单（流动性、风控、故障演练）

## 每周复盘模板

1. 我真正理解了什么（不是抄定义）
2. 这些知识将落在我系统的哪个模块
3. 哪些参数我还没有数据支撑
4. 下周要补的风险盲点
