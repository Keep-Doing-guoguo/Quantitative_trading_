# 03 交易机制与成本

## 概念名

订单类型、撮合逻辑、涨跌停、保证金、手续费与滑点

## 正式介绍

订单类型包括限价单、市价单、条件单等。撮合遵循价格优先、时间优先。  
股票有涨跌停与停牌等约束，期货有涨跌停、保证金、强平与手续费规则。  
总交易成本通常可分解为显性成本（手续费、交易所费用）和隐性成本（滑点、冲击成本）。  
滑点是预期成交价与实际成交价差值，受流动性、波动与下单方式影响。

## 通俗介绍

你下单像打车：  
- 限价单像“只愿意这个价上车”，可能等很久。  
- 市价单像“马上走”，通常更快但可能更贵。  
手续费是明面账单，滑点是你没注意到的“隐藏支出”。

## 为什么量化开发必须懂

很多策略“纸面盈利、实盘亏损”的根因就是成本模型过于理想。  
如果没有撮合与成本仿真，回测报告会系统性高估收益并低估风险。

## 在系统中的落点

- `data_handler`: 盘口深度/成交量数据接入
- `strategy`: 订单类型选择逻辑
- `risk_engine`: 下单前保证金与可用资金校验
- `execution_router`: 报单、撤单、状态回报处理
- `backtest`: 撮合引擎与成本模型
- `portfolio`: 扣费、盯市与权益更新
- `monitoring`: 下单失败率、成交延迟、滑点监控

## 常见误区

1. 误区：手续费很低可以忽略。  
   纠正：高换手策略中成本可吞噬大部分利润。
2. 误区：滑点可设为固定常数。  
   纠正：滑点与市场状态相关，常需分场景建模。
3. 误区：市价单一定更好。  
   纠正：流动性差时市价单可能出现较大冲击。

## 最小例子

同一策略在回测中使用“按收盘价成交”看起来 Sharpe 很高。加入“单边 2 bps 手续费 + 波动相关滑点模型”后，收益下降 40%，策略从可交易变为不可交易。

## 3 道自测题（含答案）

1. 题目：为什么回测必须包含隐性成本？  
   答案：因为隐性成本会显著影响实际可交易收益，忽略会高估策略表现。
2. 题目：撮合中的“价格优先、时间优先”意味着什么？  
   答案：更优价格先成交；同价位下更早进入队列的订单先成交。
3. 题目：保证金不足在系统层面应如何处理？  
   答案：应在风控前置阶段拦截订单，避免交易通道拒单或被动强平。
